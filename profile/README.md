# Kredoxi

> Steal the config. Not the secret.

Kredoxi is a security-focused runtime credential-substitution project. Its goal
is to replace credentials in application configuration with stable, non-secret
references resolved at an authenticated, policy-controlled runtime boundary.

Kredoxi is a conventional software agent, not an AI agent. A reference does not
resolve itself: applications need a supported integration or execution mechanism.
An authorised compromised application can still expose credentials it receives.
Privileged host compromise and runtime memory disclosure are not assumed protected.

The project is in early development. No production readiness, release, transparent
interception, or security guarantee is implied.
